Hoje (tela atual)

Como você quer

1. "Autódromos" abre primeiro uma lista de autódromos (Brasília agora; outros no futuro). Cada card com informações básicas.

2. Tocar num autódromo abre a tela do autódromo com: seletor de carro (ou ver recordes gerais) + resumo (melhor volta, velocidade máxima) + lista de trechos.

3. Cada trecho mostra: desenho + ponto de entrada + ponto de frenagem + V-min + PAce (ponto de aceleração) + ápice + ponto de saída.

4. A filosofia continua sendo trechos. O autódromo é só a porta de entrada pra navegar com contexto do carro.
