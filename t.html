Browser não compatível Este teste usa Web Serial API, disponível só no Chrome ou Edge (versão 89 ou mais nova) no Windows. Safari e Firefox não suportam. Se você está no Edge ou Chrome e mesmo assim aparece este aviso, abra chrome://flags/#enable-experimental-web-platform-features e ative.
Como usar 1. Liga o carro com chave em ON (a central T4000 precisa estar alimentada — não basta "Acessórios").
2. Confirma que o cabo USB da T4000 está plugado no notebook.
3. Clica em Conectar à T4000, escolhe a porta na janela do Chrome e autoriza.
4. Olha os números abaixo. Se ficarem mexendo, a USB transmite o protocolo CAN. Se ficarem em zero, a USB é só pra o software Injepro T (configuração) — vai precisar de adaptador USB→CAN.

Se zero bytes chegarem por 30 segundos A porta USB da T4000 provavelmente é só pra o Injepro T Software (programa de configuração da Injepro) e não transmite o stream CAN ao vivo. Nesse caso, você precisa de um adaptador USB→CAN ligado no chicote do carro (PCAN-USB, Kvaser, CANable, etc.). Manda print desta tela pro Claude e a gente vê o próximo passo.
