Pergunta 1 de 4

O cabo serve pra quê?

Existem duas formas bem diferentes de usar um cabo entre o iPhone e o notebook — e cada uma muda o que eu preciso construir.

Espelhar a tela do iPhone no notebook (vídeo) menos trabalho
O notebook é só uma "TV maior" do iPhone — mostra exatamente o que o iPhone mostra, só que numa tela de 10,5" em vez de 6,9". Não preciso fazer um programa pra Windows. Cabo provável: USB-C → HDMI ou USB-C → USB-C com app de captura.
Mandar dados do iPhone pro notebook, e o notebook desenha sua própria tela trabalho dobrado
Os dois aparelhos rodam programas diferentes. O iPhone captura sensores e envia "pacotinhos" pelo cabo (tipo USB ethernet). O notebook recebe e desenha o cockpit com seu próprio motor. Permite layouts diferentes em cada tela, mas dobra o código pra manter.

Pergunta 3 de 4

Onde cada aparelho fica fisicamente no carro?

Isso muda a ergonomia (qual tela o piloto olha mais) e a robustez (qual aguenta mais vibração e calor).

Os dois no painel — iPhone fixo + notebook montado ao lado
Notebook 10,5" no painel é compacto mas ocupa espaço de copiloto. Cabo curto entre eles, sem folga.
Só notebook no painel; iPhone fica escondido (bolso/cinta)
Piloto olha só o notebook na pista. iPhone trabalha "invisível" capturando sensores. Cabo precisa correr do bolso até o painel.
Só iPhone no painel; notebook fica na carona / mochila
Notebook nem vai ser olhado durante a volta — fica acordado mas o piloto não olha. Provavelmente combinado com a opção "espelho" pra revisar depois.

Pergunta 4 de 4

Se o cabo desconectar no meio de uma volta…

Cabo balança. Conector solta. Acontece. Como o sistema deve reagir?

iPhone continua sozinho gravando tudo; notebook só "perde a tela maior" segurança alta
Esta é a base do que já está pronto: o iPhone é auto-suficiente. Notebook é bônus. Quando o cabo voltar, ele "encaixa" de novo.
Notebook tenta sobreviver com sensores próprios (GPS USB, etc.) muita engenharia
Exige hardware extra no notebook (GPS USB, placa de aquisição). Sai do escopo do que está construído. Não recomendo agora.
Notebook congela e mostra um aviso enorme "CABO DESCONECTADO"
Comportamento mais simples e legível pro piloto. Volta a funcionar quando o cabo voltar a comunicar. Combina com qualquer escolha da pergunta 1.
