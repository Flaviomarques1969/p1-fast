Como ler este relatório

Cada item é um pedaço da experiência: uma tela, um bloco de tela, uma funcionalidade. Comparei o desenho aprovado (mockup HTML) com o que o app iPhone já tem hoje. Status:

  • Pronto — funciona no app, lendo dados reais do banco
  • Parcial — tela existe, mas alguns dados ainda são exemplo
  • Esqueleto — tela existe só com dados de exemplo
  • Faltando — só o desenho existe, app nem tem a tela ainda
  • Fora de escopo — não vai pro app desta fase
